# Changelog

## [1.2.0] - 2026-10-22
- Replaced OpenSEO keyword-data integration with a direct DataForSEO v3 client.
- Added explicit paid-call opt-in, environment-based credentials/market configuration, and provider-cost logging.
- Replaced the misleading DR field with referring-domain/backlink counts and updated operating references.
- Removed the unused OpenSEO MCP client.

## [1.1.0] - 2026-10-22
- Reframed the workflow around validated revenue hypotheses rather than site-count throughput.
- Added pilot/cohort gates, portfolio metrics, and explicit expand/hold/stop decisions.
- Removed random cross-domain link-network guidance, fixed copy/viewport constraints, and implied indexing/performance/revenue guarantees.
- Added rights, ad-policy, consent, cost-authorization, and local-script configuration checks.
- Reworked keyword references so trends and KD are evidence inputs, not automatic project decisions.
- Updated behavior evals to test policy, measurement, and authorization boundaries.

## [1.0.0] - 2026-10-22
- Merged `keyword-mining` (dual-track keyword mining, Trends direct pull, zero-credit fallback, persistent library) and `seo-minigame-site-sop` (end-to-end autonomous mini-game site builder, strict aesthetic discipline, game schema).
- Unified into `sep-sop` workspace skill.
- Added support for parasite/unblocked platform hosting strategies (GitHub Pages, Cloudflare Pages).
