# Reference Sites for Design Study

Use these examples selectively when they are accessible and relevant to the target game. Study usability, hierarchy, and interaction patterns; do not copy their identity, assets, code, or exact layout. They are inspiration, not mandatory design requirements.

| Site | Style Notes | Why Imitate |
|------|-------------|-------------|
| https://ganbaru.games/ | Clean, text-light, game-first | Excellent example of minimal supporting content |
| https://play2048.co/ | Classic, focused, almost no chrome | Pure game experience with just enough UI |
| https://0hh1.com/ | Elegant logic game, high polish, low clutter | Strong typography and spacing discipline |
| https://hextris.io/ | Simple arcade, immediate play | Fast to value, minimal framing |
| https://wwwtyro.github.io/Astray/ | Immersive, dark, game-centric | Strong atmosphere without extra boxes |
| https://david-peter.de/cube-composer/ | Conceptual, clean, educational restraint | Clear hierarchy, no decoration for decoration's sake |
| https://solitaireforfree.com/ | Functional, readable, low noise | Good balance of utility and cleanliness |
| https://2048game.com/ | Timeless minimalism | Sets the standard for single-game pages |

## How to Use These References

1. Select examples that match the target game and audience; if a site is unavailable, choose another or skip the comparison.
2. Note how players find controls, understand the rules, and recover from game states.
3. Adapt useful interaction ideas to the original implementation and brand.
4. Prefer clarity over matching a fixed text count, viewport ratio, color count, or number of containers.
